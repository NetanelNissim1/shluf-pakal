# שלוף (Shluf) - פק"ל חידות והפעלות שטח למדריכים

**פלטפורמת תוכן והפעלות שטח למדריכים – מותאמת מובייל (Mobile-First PWA & 100% Offline-First)**

---

## 🌟 סקירה כללית
אפליקציית **"שלוף"** פותחה במיוחד עבור מדריכי טיולים, מפקדים, מורים, תנועות נוער ומדריכי של"ח. האפליקציה מאפשרת שליפה מיידית של מעל **1,400 חידות, הפעלות, משחקים (כולל משחק טאבו אינטראקטיבי מלא) וסיפורים** ישירות מהסמארטפון – **ללא צורך בחיבור אינטרנט כלל (Offline-First)** ועם התאמה מרבית לתנאי שטח קיצוניים (שמש יוקדת או חושך סביב מדורה).

---

## 🚀 תכונות עיקריות

1. **עבודה מלאה ללא קליטה (100% Offline PWA):**
   * כל 1,415 החידות וכרטיסי הטאבו מאוחסנים מקומית במכשיר.
   * Service Worker מבצע Pre-cache לכל הנכסים לעבודה במצב טיסה.
   * ניתן להתקנה על מסך הבית (Add to Home Screen) ב-iOS וב-Android.

2. **עיצוב שטח כפול (Dual Field Mode):**
   * **מצב שמש ישירה (High Contrast Outdoor Mode):** רקע צהוב-מדברי עדין/לבן, טקסט כהה בניגודיות מקסימלית ופונטים גדולים (`19px+`) לקריאה קלה בהליכה בשמש.
   * **מצב מדורה (Amoled Campfire Night Mode):** רקע שחור עמוק (`#000000`) עם גווני אש וכתום-אמבר לשמירה על ראיית לילה ומניעת סנוור החניכים.

3. **מנגנון הגנה נגד הצצות (Anti-Peeking Mechanism):**
   * הפתרונות מוסתרים כברירת מחדל.
   * **Tap to Reveal:** לחיצה לחשיפת הפתרון.
   * **Press & Hold:** לחיצה ממושכת להצצה זמנית בפתרון (נעלמת עם עזיבת האצבע).
   * כפתור מהיר "חשוף הכל" / "הסתר הכל" לכל רשימה.

4. **כפתור הפלא: "שלוף לי!" (The Randomizer FAB):**
   * כפתור צף קבוע בתחתית המסך (באזור האגודל).
   * שליפה אקראית עם אפקט רולטה, רטט שטח (`Haptic Feedback`) וקונפטי.
   * אפשרות לסינון שליפה מכל המאגר או מקטגוריה מסוימת.

5. **משחק טאבו שטח אינטראקטיבי (Interactive Taboo Tool):**
   * מבוסס על כרטיסי הטאבו מקובץ התרבות.
   * תצוגה מוגדלת לקריאה ממרחק מול הקבוצה.
   * טיימר 60 שניות עגול עם אנימציה, סאונד מובנה וצפצוף סיום (Web Audio API - ללא קבצים כבדים).
   * החלקה (Swipe) ימינה/שמאלה להחלפת כרטיס וספירת הצלחות/דילוגים.

6. **הפק"ל שלי (Personal Pakal):**
   * שמירת שאלות נבחרות לטיול הספציפי בלחיצה על כוכב (★).
   * כפתור "שלח לוואטסאפ" המייצר הודעה מעוצבת ומוכנה לשליחה לצוות ההדרכה.

## 📂 5 קטגוריות התוכן של הפרויקט

התוכן נשאב ומפורסר ישירות מ-5 קובצי Markdown בתיקיית `content/`:
1. **שרשראות מילים ותחיליות:** חידות אותיות, חידות "פיל", "חל", "גל", "מס", "פר", "חן", "עץ".
2. **טבע, בעלי חיים וצומח:** חיות לפי א'-ב', חרוזים ותיאורים, הוא והיא בצמחים, בוטניקה ופירות.
3. **ארץ ישראל, היסטוריה וערים:** חידות חוצה ישראל, אתרים היסטוריים, ערים ויישובים.
4. **לשון, היגיון וכפל משמעות:** חידודי לשון, כפל משמעות, חידות "למה? כי...", צירופים והיפוכיהם, פלינדרומים.
5. **תרבות, שירים ישראליים וטאבו:** שירים ישראליים, חידות מפורסמים, רגע של אנגלית ותרגום מצחיק, כרטיסי טאבו.

## 🛠️ פקודות הרצה

```bash
# התקנת תלויות
npm install

# הפעלת שרת פיתוח מקומי
npm run dev

# פרסור מחדש של קובצי התוכן (במידה ונוספו חידות ל-content/)
npm run parse

# בניית גרסת Production ו-PWA
npm run build

# בדיקת גרסת ה-Production המקומית
npm run preview
```
